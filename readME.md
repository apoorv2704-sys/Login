# 🔐 Simple Login Page

A simple and beginner-friendly **Login Page** created using **HTML**.
This project is made to practice basic HTML concepts such as forms, input fields, labels, buttons, and page structure.

## 📌 Features

* Username/Phone Number input field
* Password input field
* Login button
* Simple and clean layout
* HTML form structure

## 🛠️ Technologies Used

* **HTML5**

## 📂 Project Structure

```text
Login-Page/
│
├── Login.html
└── README.md
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `Login.html` in any web browser.
4. The login page will appear.

## 🎯 Purpose

This project was created as a beginner-level HTML project to understand how **HTML forms and input elements** work.
